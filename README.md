# SIHL Synapse

Centralized platform for SIHL serving Employee, Branch, Management, Franchisee, and Remisier stakeholders through a single unified access layer.

This is a standalone project — independent of any prior SIHL initiatives (e.g. `SIHL_SSO`). All work, documentation, and artifacts for Synapse live under this folder (`C:\Projects\Synapse`) only. Sub-folders will be added under `docs/` and elsewhere as the project's needs emerge (e.g. new phases, design assets, source code).
